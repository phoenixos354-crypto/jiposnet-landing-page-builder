# Prompt: Landing Page jipos.net



Buatkan landing page single-page untuk brand internet reseller bernama **JIPOSNET** (Jitu Pos Internet), domain **jipos.net**.



## Referensi desain & struktur

Gunakan **https://jinom.net** sebagai referensi gaya dan struktur (bukan untuk disalin konten/copy-nya, hanya pola layout & nuansa). Struktur jinom.net:

1. Header — logo + nav (Produk, Tentang, Artikel) + CTA tombol WhatsApp

2. Hero — headline besar + gambar hero + CTA ke section produk

3. Section "masalah/kenapa kami ada" — storytelling problem-solution untuk bangun kredibilitas

4. Social proof — angka besar (jumlah area/provinsi, jumlah pelanggan) + peta/ilustrasi sebaran

5. Produk/layanan — grid dengan bullet fitur tiap layanan + gambar

6. CTA tengah — ajakan gabung/berlangganan + tombol WhatsApp

7. Footer — logo, tagline, link produk, link perusahaan, alamat & kontak, copyright



Nuansa: korporat tapi hangat, storytelling problem-solution, bukti sosial dengan angka, CTA WhatsApp di banyak titik (bukan form kontak konvensional).

## Section yang dibutuhkan

1. **Hero** — headline "Internet cepat & stabil untuk [area layanan Rawajitu/Tulang Bawang]" + subheadline singkat + CTA tombol WhatsApp

2. **Kenapa JIPOSNET** — 2–3 poin keunggulan (harga terjangkau, support lokal cepat tanggap, jaringan stabil) — pakai placeholder copy dulu, bisa direvisi

3. **Paket layanan/harga** — buat 3 kartu paket dengan placeholder harga & kecepatan (akan diisi data asli nanti)
